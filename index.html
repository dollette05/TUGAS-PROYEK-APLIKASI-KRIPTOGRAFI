Cara kerja singkat

Tiga langkah saja. Tidak perlu paham kriptografi untuk memakainya.

1

Masukkan data + kata sandi

Ketik teks atau pilih berkas, lalu buat kata sandi. Dari kata sandi ini dibuat kunci acak lewat PBKDF2 (100 ribu iterasi + salt acak).

2

Klik Enkripsi

Data dikunci dengan AES-256-GCM + nomor acak (IV) baru setiap kali. Hasilnya berupa kode Base64/Hex atau file .enc.

3

Buka dengan kata sandi yang sama

Hanya kata sandi yang benar yang bisa membuka. Kata sandi salah atau file diubah sedikit saja — sistem langsung menolak.

GCM vs CBC — bedanya apa?

Dua pilihan mode di aplikasi ini. Intinya: GCM untuk dipakai, CBC untuk belajar perbandingannya.

AES-256-GCM Disarankan

Mode modern, standar TLS 1.3 & HTTPS

  • Ada segel pengaman (auth tag) — perubahan 1 byte langsung ketahuan dan ditolak.
  • Pakai nomor acak baru tiap enkripsi, jadi hasilnya selalu beda dan lebih cepat.
  • Cocok untuk semua kebutuhan: tugas, arsip pribadi, dokumen penting.

AES-256-CBC Pembanding

Mode klasik, tanpa segel bawaan

  • Tidak ada segel pengaman — file yang diubah tetap terbuka (rusak tanpa peringatan).
  • Prosesnya berantai dan sedikit lebih lambat, butuh padding khusus.
  • Hanya untuk perbandingan di halaman Pengujian, bukan untuk data asli.

Detail teknis (CTR, GHASH, auth tag 128-bit, Padding Oracle) dibuktikan lewat angka di halaman Pengujian.

Privasi Anda terjaga

Kunci dibuat dari kata sandi Anda di perangkat ini memakai WebCrypto API. Tidak ada akun, tidak ada server, tidak ada data keluar. Jika lupa kata sandi, data tidak bisa dikembalikan — simpan baik-baik.
